# Decisiones del Project Ledger

Estados válidos:

- `ACCEPTED`
- `PROPOSED`
- `SUPERSEDED`
- `REJECTED`

Cada DEC conserva contexto, decisión, consecuencias y referencias. Una conversación o exploración no se convierte en decisión por existir.

Los registros históricos en `docs/chatgpt/08_DECISIONES.md` se conservan como antecedente; las DEC de esta carpeta son la forma durable nueva.
