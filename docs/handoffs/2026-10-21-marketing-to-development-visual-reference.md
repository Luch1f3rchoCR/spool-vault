- login/acceso;
- onboarding;
- empty states;
- demo mode;
- landing/superficies públicas;
- momentos de bienvenida e ilustraciones.

## Qué NO cambia

- dashboard operativo;
- formularios;
- navegación;
- contratos de interacción;
- datos;
- tokens Proper V1;
- funciones publicadas.

No implementar cambios de UI a partir de este handoff sin una decisión/spec posterior.
